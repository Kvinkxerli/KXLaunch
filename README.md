## 🌟 Ключевые особенности KXLaunch

* **🖼️ Кастомный Альбом с аппаратным видеоплеером (NVDEC):**
  Полноценная замена стокового Альбома прямо внутри меню:
  * **Прямое воспроизведение видеозаписей:** Записанные 30-секундные клипы Switch (`.mp4`) автоматически воспроизводятся прямо внутри кастомного Альбома со звуком в 60 FPS с аппаратным декодированием NVDEC (без необходимости запускать сторонние системные апплеты).
  * **Удобное управление плеером:** Пауза и продолжение по кнопке **A**, плавная покадровая перемотка на **Влево / Вправо**, переключение между клипами на **L / R**, режим слайдшоу на **X**.
  * **Сенсорный просмотр:** Одиночный тап пальцем по экрану мгновенно открывает фото в полный экран или начинает воспроизведение видеоклипа.
  * **Человеческие названия и даты:** Вместо непонятных кодов файлов (вроде `2024102513450000-010056E00853A000.jpg`) отображаются настоящие названия игр из вашей библиотеки, тип медиа (`Снимок экрана` / `Видеозапись`) и дата/время съёмки на русском языке.
  * При необходимости стоковый системный альбом можно открыть нажатием кнопки **Y**.

* **📲 Беспроводная загрузка музыки с телефона (QR-код + Web-интерфейс):**
  Нажмите **Y** в плеере Музыка — на экране консоли появится яркий QR-код и локальный адрес. Наведите камеру телефона (iPhone / Android) и загружайте треки (`.mp3`, `.flac`, `.ogg`, `.wav`, `.m4a`, `.opus`) напрямую на SD-карту Switch через мобильный веб-интерфейс с отображением прогресса и списком загруженного. Для ПК также всегда доступен быстрый USB MTP или FTP.

* **📦 Умное определение и отображение архивированных игр:**
  * Иконки игр, архивированных через системные настройки Nintendo Switch, автоматически отображаются полупрозрачными и монохромно-серыми во всех 8 макетах интерфейса.
  * Точный алгоритм детекции на основе флагов `NsApplicationView` (`AppViewFlag_CanLaunch` и `AppViewFlag_HasMainContents`) корректно определяет архивированные игры, даже если на консоли установлены обновления, DLC или остались пустые метаданные весом 0 байт.
  * Динамический опрос мгновенно обновляет статус игр и картриджей без перезапуска меню.
  * При попытке запуска архивированной игры меню выводит безопасное уведомление: `Игра архивирована` вместо вылетов и системных сбоев.

* **⚡ Оффлайн-выбор профиля без назойливой привязки к Nintendo:**
  При запуске игры (если на консоли 2 и более аккаунтов) открывается красивое меню выбора пользователя с аватарами и никнеймами. В отличие от стокового апплета Horizon, выбор профиля в KXLaunch **не требует привязки к аккаунту Nintendo** и не блокирует запуск игр на непривязанных или оффлайн-профилях в кастомной прошивке (CFW).

* **🛡️ Идеальная совместимость с оверлеями (Tesla-Menu / Ultrahand):**
  При открытии любого стороннего оверлея поверх меню KXLaunch отслеживает статус фокуса окна (`AppletFocusState_InFocus`) и полностью блокирует обработку кнопок и тачскрина в меню, предотвращая паразитные нажатия под оверлеем.

* **🎮 Мгновенный контроль запущенной игры:**
  При нажатии кнопки **X** на запущенной игре меню автоматически фокусируется на пункте **Закрыть игру** (больше не нужно вручную листать опции). Активная игра всегда выделена анимированным статусом во всех макетах интерфейса.

* **🕹️ Плавный перехват сенсорной инерции геймпадом:**
  При прокрутке списка игр пальцем с инерцией (fling) любое действие на геймпаде (крестовина, аналоговые стики) мгновенно подхватывает управление без фризов и задержек.

* **🛠️ Исправление вылетов игр и авто-создание сохранений:**
  Решена проблема крашей при первом запуске требовательных игр на движках Unreal Engine / Unity (например, *A Hat in Time* с ошибкой `0x527d4` / `NN_ABORT`). Проект корректно создает обязательные разделы сохранений (`owner_id`, `Thumbnail` только для профильных данных, `None` для системных/временных/кэш-данных).

* **📦 Безупречный запуск Homebrew:**
  Собственный загрузчик `hbloader` с поддержкой запуска в режиме апплета (Album) и полнопамятном режиме приложения (через donor-игру). Сгенерированы и встроены все необходимые дескрипторы `main.npdm`, исключающие вылеты в главное меню при выборе любого `.nro`.

* **🔊 Приятные звуковые эффекты (UI SFX):**
  Полноценное озвучивание интерфейса: перемещение по списку игр (`Move`), листание страниц (`PageLeft`/`PageRight`), выбор и запуск (`Confirm`/`Click`), возврат (`Back`).

* **📅 Полная локализация даты и верхней панели:**
  Дата и время в верхнем левом углу отображаются на чистом русском языке с правильными сокращениями дней недели и месяцев (`12:00 Вс окт 25`).

* **🧹 Очищенное и оптимизированное меню:**
  Удалены устаревшие и неиспользуемые компоненты (встроенный браузер и неработающие виджеты), за счет чего меню работает с максимальной частотой кадров и минимальным расходом батареи.

* **🔄 Встроенная проверка обновлений KXLaunch:**
  Проверка свежих релизов напрямую из официального репозитория [Kvinkxerli/KXLaunch](https://github.com/Kvinkxerli/KXLaunch).

* **🎨 9 стилей интерфейса и глубокая кастомизация:**
  Минималистичный **Line** по умолчанию, **4R (Latitude)** , **Grid** (плитки), **Flow** (3D Coverflow), **Deck** (в стиле SteamOS), **Shelf**, **Cover**, **List**, **XMB** (в стиле PSP/PS3), поддержка видео-обоев MP4 с аппаратным декодированием NVDEC, наборов иконок и TTF/OTF шрифтов.

* **📁 USB MTP (передача файлов по кабелю):**
  Встроенный быстрый MTP-сервер: подключайте Switch к компьютеру по USB-C и передавайте файлы напрямую на SD-карту прямо из меню.

## 🎮 Управление в меню

### Главный экран
| Кнопка | Действие |
| :---: | :--- |
| **A** | Запуск игры / выбор профиля / подтверждение |
| **B** | Назад / отмена |
| **X** | Контекстное меню (на запущенной игре — быстрое закрытие) |
| **Y** | Мгновенный поиск игр по названию |
| **D-Pad / Стик** | Навигация по играм и меню |
| **L / R** | Быстрое перелистывание страниц |
| **ZL / ZR** | Быстрый переход в начало / конец списка |
| **+ (Плюс)** | Меню управления питанием (сон, перезагрузка, пейлоад) |
| **- (Минус)** | Меню настроек оформления и тем |

### В Альбоме
| Кнопка / Жест | Действие |
| :---: | :--- |
| **Тап по экрану** | Открыть снимок во весь экран / Запустить видеозапись |
| **A** | Полноэкранный просмотр / Пауза и продолжение видео |
| **D-Pad Влево / Вправо** | Перемотка видеоклипа назад и вперед |
| **L / R** | Предыдущий / следующий снимок или клип |
| **X** | Запуск слайдшоу |
| **Y** | Открыть системный альбом Nintendo |
| **B** | Выход из просмотра / назад в меню |

## 📥 Установка на Nintendo Switch

1. Перейдите на страницу [Релизов](https://github.com/Kvinkxerli/KXLaunch/releases) и скачайте архив **`kxlaunch.zip`**.
2. Распакуйте архив прямо в корень вашей SD-карты (`sdmc:/`), подтвердив замену файлов при необходимости.
3. Убедитесь, что на SD-карте присутствуют:
   - `sdmc:/atmosphere/contents/0100000000001000/exefs/main` и `main.npdm` (системный демон qlaunch)
   - `sdmc:/slaunch/bin/sMenu/main` (интерфейс меню)
   - `sdmc:/slaunch/bin/hbloader/main` и `main.npdm` (загрузчик homebrew)
   - `sdmc:/slaunch/lang/ru.txt` (русская локализация)
4. Перезагрузите Nintendo Switch в кастомную прошивку (Atmosphère).

## 🛠️ Сборка из исходников

### Необходимые инструменты
* Установленный тулчейн **devkitPro** для Nintendo Switch:
  * `devkitA64`
  * `libnx`
  * `AtmosphereLibs`
* Библиотеки Switch:
  `switch-dev`, `switch-sdl2`, `switch-sdl2_ttf`, `switch-sdl2_image`, `switch-sdl2_mixer`, `switch-curl`, `switch-mbedtls`.

### Команды для сборки
```bash
# Сборка всех компонентов проекта и подготовка структуры SdOut/
make

# Создание архива релиза kxlaunch.zip
make package

# Полная очистка скомпилированных файлов
make clean
```
