# Button prompt icons

Nintendo Switch button glyphs (A/B/X/Y, L/R, +/-, D-pad, directional arrows,
right stick, and the Joy-Con pair used for the Controllers icon) are from
**Xelu's "Free Controller and Key Prompts"** pack by Nicolae "Xelu" Berbece /
Those Awesome Guys (<https://thoseawesomeguys.com/prompts/>), released under
CC0 (public domain) - credit optional, but given anyway per this project's
usual practice for third-party art.
